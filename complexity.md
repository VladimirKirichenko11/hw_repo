# 1. Переборное решение
Сложность: O(N! * N^2)
Обоснование:
- Генерируются все перестановки N чисел: N! вариантов
- Для каждой перестановки выполняется проверка:
  Проверяется каждая пара ферзей: O(N²)
# 2. Рекурсивное решение
Сложность: O(N!) в худшем случае, обычно меньше
Обоснование:
- В худшем случае алгоритм перебирает все расстановки: N!
- Однако backtracking отсекает неподходящие варианты на ранних этапах
- На практике для N=8 алгоритм проверяет около 15,7 тысяч расстановок из 8! = 40320
# 3. Оптимизированное решение (с битовыми масками)
Сложность: O(N!) в худшем случае, но с малыми константами
Обоснование:
- Асимптотическая сложность та же, что и у backtracking: O(N!)
- Однако операции с битами выполняются за O(1) на аппаратном уровне
- Отсутствие дополнительных проверок и манипуляций с массивами
- Значительно меньше накладных расходов на рекурсивные вызовы

# Память:
- Все алгоритмы используют O(N) дополнительной памяти
- Битовое решение использует O(1) памяти для хранения состояний (целые числа)
